# Lattice documentation provenance

The eight text files in this directory are copied byte-for-byte from the two
Lattice C 5.0 documentation ADFs in `../media/`.  They are already plain
text; no PDF conversion or editorial normalization was applied.

They describe the 5.0 base release.  The compiler disks in this corpus carry
5.02 versions of `lc`, `lc1`, `lc2`, and `blink`, while retaining the older
readme and volume labels.  The manuals remain useful authoritative evidence
for the install layout, Lattice assigns, BLINK library syntax, and the
standard hierarchical overlay `WITH` file format.
